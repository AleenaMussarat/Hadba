# SAMDAN CMS

This is a [Strapi](https://strapi.io) backend used to manage the SAMDAN website's **menu** (categories, items, prices, photos) and **hero carousel** (homepage slides). Everything else on the site (nav, story, contact, footer, reservation form) stays static in the frontend's `src/i18n/translations.jsx` — only the menu and carousel are CMS-driven.

## Running it

```bash
cd cms
npm run develop
```

First run will:
- Build and start the admin panel at [http://localhost:1337/admin](http://localhost:1337/admin).
- Seed the menu categories/items and carousel slides (with images) automatically from the site's existing content, and open public read access to them — this only runs once (it skips itself if data already exists).

Since this is the **first time** the CMS runs, Strapi will prompt you to create the first admin account the moment you open `/admin` in a browser. That login is the "CRM" — anyone with an account can add/edit/remove menu items and carousel slides from then on.

## Where to edit things

In the admin panel's **Content Manager**:
- **Menu Category** — the four menu sections (e.g. "Signature Kabsa"). Has an `order` field controlling display order.
- **Menu Item** — individual dishes: name, description, price, photo, "featured" flag (shows the "Chef's Pick" badge), which category it belongs to, and `order` within that category.
- **Carousel Slide** — the homepage hero carousel: badge, title, subtitle, photo, `order`.

Each of these has an **EN / AR locale switcher** at the top of its edit screen (name/description/badge/title/subtitle are translated per-locale; price, photos, the featured flag, and ordering are shared across both languages automatically).

## How the frontend uses this

The Vite app (`../src/services/strapi.js`) reads from this CMS's public API (`VITE_STRAPI_URL` in `../.env`, defaults to `http://localhost:1337`). **If this CMS isn't running, the site still works** — it silently falls back to the static content in `translations.jsx` instead of breaking.

## Notes

- Uses SQLite (`.tmp/data.db`, gitignored) — zero external database setup needed for local dev. For production, point `DATABASE_CLIENT` at Postgres/MySQL (see `config/database.js`).
- Uploaded images live in `public/uploads` (gitignored) — also regenerated by the seed script on a fresh install.
